# Java Design Pattern Examples

## Project Context

This project was developed as part of the **T2T (Theory to Trade) program** for the **Architecture** module.

This repository contains a collection of simple, self-contained Java projects, each designed to provide a clear and practical demonstration of a fundamental software design pattern.

## Overview

The goal of this project is to serve as a learning resource for understanding the core concepts of creational design patterns. Each pattern is implemented in its own directory and includes a detailed `README.md` file explaining its purpose, use cases, and instructions on how to compile and run the specific example.

## Included Design Patterns

Below is a list of the design patterns demonstrated in this project.

### 1. Abstract Factory
-   **Purpose**: Provides an interface for creating families of related or dependent objects without specifying their concrete classes.
-   **[View Details](./AbstractFactory/README.md)**

### 2. Builder
-   **Purpose**: Separates the construction of a complex object from its representation, allowing the same construction process to create various representations.
-   **[View Details](./Builder/README.md)**

### 3. Simple Factory
-   **Purpose**: Provides a centralized creation method to hide instantiation logic from the client. Note: This is a common programming idiom, often confused with the formal "Factory Method" pattern.
-   **[View Details](./Factory/README.md)**

### 4. Prototype
-   **Purpose**: Creates new objects by copying an existing object, known as a prototype, rather than creating them from scratch.
-   **[View Details](./Prototype/README.md)**

### 5. Singleton
-   **Purpose**: Ensures a class has only one instance and provides a global point of access to it.
-   **[View Details](./Singleton/README.md)**

## How to Use This Repository

To explore a specific design pattern:
1.  Navigate into the corresponding directory (e.g., `cd Builder`).
2.  Read the `README.md` file within that directory for a detailed explanation and instructions.
